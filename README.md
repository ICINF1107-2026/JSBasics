# JS Basics — Ejercicios de JavaScript 

Colección de ejercicios guiados para aprender los fundamentos de JavaScript.
Cada ejercicio es una función con `// TODO` que debes completar.

## Cómo usarlo

1. Abre `index.html` en tu navegador (doble clic basta).
2. Abre la consola con `F12` → pestaña **Console**.
3. Edita `scripts.js` y completa las funciones.
4. Recarga la página: el bloque `VERIFICACIÓN` imprimirá tus resultados
   (`PASS` / `FAIL` y el total de ejercicios resueltos).

## Estructura

| Archivo        | Contenido                                    |
| -------------- | -------------------------------------------- |
| `index.html`   | Página con los elementos del ejercicio 6 (DOM) |
| `scripts.js`   | Ejercicios + verificación automática         |
| `styles.css`   | Estilos mínimos de la página                 |
